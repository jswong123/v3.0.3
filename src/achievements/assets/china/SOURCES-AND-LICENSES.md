# 中国历史勋章图像资源状态

本版不重绘真实勋章纹样。已核实来源的图片可在联网环境通过 Wikimedia Commons 的 Special:FilePath 加载；离线时需另行下载具有许可的图片放入本目录，并在 AchievementUI.js 中配置本地文件。

- CN-009 一级解放勋章：何基沣获颁实物照片，作者 Huanokinhejo，CC BY-SA 4.0。https://commons.wikimedia.org/wiki/File:First-Class_Liberation_Medal_Awarded_to_He_Jifeng_by_the_People%27s_Republic_of_China_in_1955.jpg
- CN-001 至 CN-012 勋略：Wikimedia Commons 上的独立 SVG 图像，原文件通过 `RIBBON_COMMONS` 指定；这些是第三方矢量参考，并非博物馆认证的原版照片，需进一步历史核对。
- 其余勋章实物图：尚未获得可直接打包的已核实素材，因此保留明确的待核实提示。

注意：在线图片需要联网，且可能受到浏览器跨域、网络或源站策略影响。未将有版权限制的博物馆照片直接嵌入游戏。
